# Changelog

## 0.1.0

- Installers for x64 and ARM64 Windows, macOS, and Linux.
- Bundled Windows OpenSSH client with authenticated local prompt transport.
- Native Windows Credential Manager and macOS Keychain storage, private application data, and desktop-lock handling.
- Automatic daily signed-update checks, opt-out, download progress, and safe installation after active work closes.
- Release workflows verify signed update files and complete platform coverage before publication.

See RELEASE_NOTES.md for prerequisites and operating-system signing limitations.
